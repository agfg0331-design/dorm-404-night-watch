# 《404宿舍：夜间监控》

一款可直接在桌面浏览器运行的中文心理恐怖监控网页游戏原型。

## 当前版本

- 一局完整的 00:00—06:00 值班流程（正常速度约 10.8 分钟）
- 第一视角值班室：监控在左、手机在右，可分别拿起操作
- 实物化旧安卓手机：手持机身、磨损透明壳和浅灰绿实时界面，不再使用悬浮黑色面板
- 6 路监控：404 宿舍、四楼走廊、公共洗衣房、值班室、楼梯间和一楼大厅
- 20 条带随机偏移的事件链，异常按“开始—变化中—完成—消失”实时推进
- 椅子翻倒、真实碎窗与走廊人影采用专用场景帧，并与撞击、脚步、震动时间轴同步
- 区域 + 类别双重判定的异常上报
- 漏报、误报、危险程度与系统信任机制
- 与异常绑定的手机线索，中后期会出现错误或矛盾信息
- 05:47“自己”来电与后期“不要回头”选择；06:00 后停止计时和判定
- 上报不暂停游戏，只把时间降至 42%，并强化心跳、呼吸与脚步
- 回头与不回头都有独立的慢节奏视听段落，动画结束后才进入结局
- Web Audio 分轨氛围音乐和程序化环境声：滴水、动物声、椅脚摩擦、碎玻璃、脚步、震动、敲门等

## 运行

直接打开 `dist/index.html` 即可游玩。

如浏览器限制本地音频或资源加载，可在项目目录运行：

```bash
npm run dev
```

然后访问终端显示的本地地址。

## 操作

- 点击值班室里的监控或手机进入对应界面
- 数字键 `1`—`6` 放大并切换监控
- `R` 直接拿起手机进入异常报告
- `Esc` 放下手机并返回先前画面

```text
│   └── main.js      # 交互、渲染、剧情与结局

└── style.css
```
